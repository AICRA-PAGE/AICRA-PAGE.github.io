## 프로젝트 배경

프롬프트 인젝션 방어는 흔히 “외부 문서의 명령을 따르지 말라”는 문제로 설명됩니다. 그러나 에이전트는 명령뿐 아니라 JSON 필드, 도구 호출 결과, DOM 요소 식별자, 파일 출처와 같은 **구조화된 데이터**도 해석합니다. 공격자가 이 구조를 흉내 내면 모델은 비신뢰 데이터를 신뢰된 메타데이터로 오인할 수 있습니다.

이 프로젝트는 특정 제품을 공격하는 것이 목적이 아닙니다. 에이전트의 컨텍스트 조립 과정에서 데이터가 어떤 신뢰 등급으로 들어오고, 그 등급이 실제 실행 권한까지 어떻게 전파되는지를 재현 가능한 방식으로 측정하려는 공개 연구 제안입니다.

## 기본 원칙

- 실제 계정·서비스·운영 데이터가 아닌 로컬 시뮬레이션만 사용합니다.
- 공격 코드는 영향 범위를 제한하고 악용 가능한 자격증명을 포함하지 않습니다.
- 제품별 결과를 공개하기 전 책임 있는 제보와 검토 절차를 거칩니다.
- 모델 거부율만으로 방어 성능을 판단하지 않고 최종 실행 결과를 측정합니다.

## 참여가 필요한 분야

에이전트 프레임워크, 브라우저 자동화, MCP·도구 게이트웨이, 접근제어 정책, 보안 평가와 통계 분석 경험을 가진 연구자와 실무자의 참여를 기다립니다.
